# assets

Shared creative assets used by the media engines: `luts/` (color, Phase 8),
`fonts/` (captions and titles, Phase 7), `sfx/` and `music/` (Phase 8),
`graphics/` (Phase 7). Licensed material only.

`sfx/` holds sound effects **synthesised** with FFmpeg by `sfx/generate.sh`
(pop, whoosh, ding, tick, notify; 48 kHz stereo FLAC at −18 LUFS) — no
third-party recordings. Components reference them as `sfx/<name>`.
