# ADR-0013 — Motion graphics are a Remotion overlay layer; FFmpeg composites

**Why.** Spec §19–20 and rule 19: Remotion draws motion graphics and captions, it is not the post-production engine. Agents may only place registry components, and those components must render the same way every time at any output size. The VPS has two shared cores for all media work.

**Impact.** The registry (`synthcut_timeline.registry`) gives each of the 15 components a typed props model; `validate_plan` enforces it (`E_COMPONENT_PROPS`) and `python -m synthcut_timeline.schema` exports the JSON Schema from which the Remotion app's TypeScript types are generated (`make motion-types`), so Python and React cannot drift — a test checks that both registries list the same names. `build_overlay` turns a validated plan into `overlay/1`: frames instead of seconds, props with every default filled in, platform safe zones per aspect ratio, and caption lines on the *output* timeline (transcript words mapped through the main track's source ranges and speed; a line never spans a cut). One Remotion composition renders the whole layer on a transparent background. Measured on 300 frames at 720×1280: capturing frames costs 8 s, ProRes 4444 encoding 11 s, VP8 with alpha 63 s — so the layer is ProRes 4444 (mostly transparent, ~1.4 MB/s), which FFmpeg decodes with alpha natively and overlays by timestamp (a 30 fps layer sits correctly on 29.97 fps footage). The overlay runs at the source rate capped at 30 fps. Remotion, its bundle and Chrome Headless Shell live in the media image; the one media worker takes both the `cpu` and `render` queues, so at most two cores are ever busy. Fonts (Montserrat, Inter; OFL) are bundled with Latin, Latin Extended, Cyrillic and Cyrillic Extended subsets, so Uzbek Latin (o‘ g‘) and Uzbek Cyrillic (Қ Ғ Ҳ Ў) render without fallback. Sound effects are synthesised with FFmpeg (`assets/sfx/generate.sh`) — no third-party recordings to license.

**Licensing.** Remotion is free for individuals and for companies with up to three employees; larger companies need a Remotion company licence. The owner must confirm which applies before commercial use at scale.

**Alternatives.** FFmpeg `drawtext` / ASS subtitles (no component system, weak animation); Remotion rendering the full composite including the footage (spec rule 19, and Chrome decoding 4K video is far slower than FFmpeg); a WebM/VP8 layer (5.6× slower to encode); a PNG sequence (same speed as ProRes, thousands of files).

**Decision.** Remotion renders a transparent ProRes 4444 layer from `overlay/1`; FFmpeg composites it.
