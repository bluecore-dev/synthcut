# ADR-0012 — Shot analysis is measured first, described by a vision model second

**Why.** Spec §12 asks the Video Analysis agent for framing, faces, camera motion, focus, exposure, blur, duplicates, bad takes, silences *and* semantics. Most of that is measurable from pixels and audio; asking a vision model to estimate sharpness or count seconds of speech is slower, costs per call, and is not repeatable. No model key exists yet, and the Director (Phase 6) needs the measured part regardless.

**Impact.** `analysis.asset` (cpu queue, after ingestion, before transcription) measures every shot of the 720p proxy: a 320 px grayscale stream at 1–4 fps (memory-mapped from scratch), per frame luma/crush/clip, Laplacian sharpness and phase-correlation motion; three colour stills per shot for YuNet faces (CPU, 230 KB model in the package) and a JPEG sheet; Silero VAD on the speech track for speech per shot. Each shot becomes a `clipanalysis/1` record (`clip_analyses`) with shot type, camera motion, quality scores, flags (blurry, underexposed, overexposed, shaky, frozen, black, too_short, duplicate) and a usable score. Duplicates are retakes of the same framing — a 64-bit dHash within 6 bits of an earlier shot of the project — and are information for the Director, not a penalty. Calibrated on the first real clip (162 s, 16 shots, 43 s on two cores): sharpness 100 → 0 and 2500 → 1 on a log scale; blur is flagged absolutely or relative to the footage's own median, since texture differs per scene. The records carry `source: "metrics"`; the vision agent (5b) fills `subject` / `semantic_description` and may lower `usable_score` for content reasons, never re-measures.

**Alternatives.** Vision model for everything (cost, latency, not reproducible, no key); PySceneDetect / MediaPipe (heavier dependencies for what OpenCV + numpy already do); full-resolution analysis (the 720p proxy is enough to judge focus at screen size, and 9× cheaper than 4K).

**Decision.** Measured analysis now, vision description layered on top when a model is configured.
